2006 buddy icons.

Sorted out of Mary Kate's "2006 Icons/Photos" folder, September 2026. Kept:
perfectly square only, native 90px or larger so nothing is ever displayed
bigger than it was saved, exact duplicates removed. 141 files, 39 of them
animated.

These are used as the buddy icon on Confessions & Vibes. A screen name is
hashed to a number and that number picks a file, so one person keeps the same
icon every time they post without anything being stored about them.

Anything not square went to ../photos instead. Those were saved to be resized
for a MySpace page, not to be an icon.
